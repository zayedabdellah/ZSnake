# ZSnake

A simple Snake game implemented in Python using Pygame.

## Features

- Classic Snake gameplay
- Start menu with high score display and color selection
- Customizable snake color (green, red, blue, yellow)
- Score tracking with persistent high score
- Remembers last selected snake color
- Game over screen with options to play again or exit

## Requirements

- Python 3.x
- Pygame

## Installation

### Windows

1. Download and install Python from [python.org](https://www.python.org/downloads/).
2. Open Command Prompt and run: `pip install pygame`

### macOS

1. Download and install Python from [python.org](https://www.python.org/downloads/).
2. Open Terminal and run: `pip install pygame`

### Linux

1. Install Python using your package manager, e.g., `sudo apt install python3` on Ubuntu.
2. Install pip if not installed: `sudo apt install python3-pip`
3. Run: `pip install pygame`

## Running the Game

Navigate to the project directory and run:

```bash
python snake.py
```

The game will start with a menu where you can view the high score and select your snake color using the left/right arrow keys or by clicking the preview. Your last selected color will be remembered for future games. Click "Start Game" or press Enter to begin.

Available colors: green, red, blue, yellow

## Controls

- Arrow keys to move the snake
- Eat the red food to grow and increase score
- Avoid hitting the walls or yourself

Enjoy the game!
